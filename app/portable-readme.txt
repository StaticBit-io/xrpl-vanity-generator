XRPL Vanity for Windows

Run "XRPL Vanity.exe". Nothing is installed.

Windows may stop the first start with "Windows protected your PC", because the
file is not code-signed yet. Click "More info", then "Run anyway".

Keep the "app" folder next to "XRPL Vanity.exe": the application lives there.

Your results and settings are stored in
%LOCALAPPDATA%\StaticBit\io.staticbit.vanity
To remove the application, delete this folder and that one. Deleting this
folder alone leaves your results, seeds included, on the disk.

More: https://xrpl-vanity.staticbit.io/desktop/
