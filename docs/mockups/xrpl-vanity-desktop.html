Reading the frame. One page, one primary action. Patterns are chips with their position and case; an unreachable pattern shows its warning under the chip and never blocks the others. The estimate updates on every edit. Devices list the CPU first with its thread slider, then every GPU device from both backends; OpenCL CPU implementations carry a yellow [cpu] tag and are unchecked by default. Live tiles keep their height while empty, so nothing jumps when the search starts.

Close XRPL Vanity?

A search keeps running while the window is in the tray. You will get a notification when a match is found.

The close button never kills a search silently. The first time, a modal in the page (not a system dialog) offers "Minimise to tray" as the primary action; with "Remember my choice" the answer is stored and the prompt never returns. It can be changed in Settings. Exit stops the session cleanly first.
