桌面应用

搜索靓号地址，加密保存结果，并把钱包转到手机上。

获取方式

应用即将上架 Microsoft Store。在此之前，可以从源代码编译。

  • Windows 10 1809（内部版本 17763）或更高版本，x64。
  • Microsoft Edge WebView2 运行时。Windows 11 和较新的 Windows 10 更新已自带。
  • 如需在显卡上搜索，需要 NVIDIA 驱动（CUDA，2018 年及之后的 Turing 显卡）或任意已安装的 OpenCL 平台。两者都没有时，应用会在处理器上搜索并给出提示。

教程

首次打开应用时，它会带你完整走一遍一次真实的搜索，从添加单词到看到结果及其二维码。找到的匹配不会保存，结束后你自己的单词和设置都会恢复。这个提示只出现一次：如需再次学习，请在“设置”页面点击开始教程。

搜索

添加你的单词

输入一个单词，选择位置，然后作为规则添加：开头为、结尾为、任意位置，或开头和结尾为，后者要求两部分出现在同一个地址中。规则默认不区分大小写，除非你关闭这一选项；一次搜索可以包含许多规则。

地址中不存在字符 0、O、I 和 l。它们会被替换为 o、i 和 L，规则会在你输入的内容旁显示替换结果。

紧跟在开头 r 之后的字符是受限的，所以有些单词比按长度推算的稀有约 23 倍。勾选从第 2 或第 3 个字符开始可以让单词晚一个字符开始。如果这样至少能快一倍找到，应用会在规则上建议你开启。它默认关闭，因为会改变地址的读法。

保存列表和载入列表把一组规则保存在文本文件中。载入时会追加到屏幕上的规则，并跳过重复项。

选择搜索设备

勾选处理器并设置线程数，再勾选应用找到的 CUDA 和 OpenCL 设备。它们可以同时运行。

显卡负载控件设定显卡工作的时间比例，范围 25% 到 100%。数值越低，显卡留给其他应用的时间越多，更改会立即作用于正在进行的搜索。

查看估算

开始之前，页面会显示平均需要检查多少个地址才能得到一个匹配，以及在所选设备上的预计用时。估算使用每个设备上次测得的速度。第一次使用时还没有测量值，所以请点击测量速度或先搜索一次。

开始搜索

页面会显示当前速度、已检查的地址数和匹配。每个匹配都会进入结果列表，附带地址、规则、设备和时间。“设置”中的 N 个匹配后停止会自动结束搜索。

长时间的搜索可以在托盘中继续运行，负载控件也在托盘菜单里。每次出现匹配或搜索结束时，都会有通知提醒你。

结果和历史

历史中保存着应用存下的每一个结果。可以用文本框按地址和模式筛选，也可以用模式列表筛选。勾选若干行，或使用全选显示的结果，即可一起导出或删除。

删除结果无法撤销：种子会随之消失，除非你在别处另存过，否则账户也随之丢失。

TSV 导出文件以明文包含种子。它会保存到你选择的位置，且没有任何保护，请把这个文件当作机密对待。

种子

种子控制着它对应的账户。种子在各处都是隐藏的，直到你点击显示；15 秒后或离开页面时会再次隐藏。复制的种子会在 30 秒后从剪贴板清除，除非你在此之前复制了别的内容。这两个时间都可以在“设置”中修改。

复制的种子不会进入 Windows 剪贴板历史，也不会参与剪贴板同步。

结果保存在一个文件 results.dat 中，并用 Windows 数据保护 API（DPAPI）加密。只有写入该文件的 Windows 账户才能读取它，因此结果不能转移到其他账户或其他电脑。种子不会出现在日志、通知或托盘菜单中。

卸载应用会删除 results.dat 及其中的所有种子。请先保存你想保留的种子。

把钱包转到手机上

结果上的二维码按钮会显示该钱包，显示二维码会显示所有选中的行。用 StaticBit 手机钱包扫描该码，它会根据码中的备份格式恢复钱包。一个码最多容纳 22 个钱包，设置密码时为 21 个。

如果有人可能看到你的屏幕，请设置密码。密码是可选的，用于加密二维码。没有密码时二维码不加密，对话框会提示这一点。二维码从不写入磁盘，60 秒后会自动隐藏。

单独的种子也可以显示为只含一个钱包的二维码。这种码从不加密：它不接受密码，对话框会提示这一点。StaticBit 钱包同样可以扫描它。

每项更改都会立即生效：没有保存按钮。应用的语言也在这里选择。
