常见问题

窗口打开后一片空白，或提示无法访问此页面

缺少 WebView2 运行时。请安装 Evergreen WebView2 运行时，然后重新打开应用。

除了处理器之外没有列出其他设备

应用通过 NVIDIA 驱动查找 CUDA，通过已安装的驱动查找 OpenCL。请安装或更新显卡驱动，然后点击“设备”卡片上的刷新按钮。无需重启。

搜索时某个设备行变红

该设备出错了，例如驱动重置之后，错误信息显示在该行中。其他设备会继续运行。只有全部设备都失败时，搜索才会结束。

历史记录为只读

应用无法读取或写入结果文件，“历史”页面上的横幅会说明原因。通常是文件由另一个 Windows 账户写入，或从另一台电脑复制而来：结果只能由写入它的账户打开。把该文件移到别处，即可开始新的历史记录。

从来没有收到通知

“设置”页面会显示 Windows 是否接受了通知。如果已接受，请在 Windows 设置的“系统”和“通知”中确认 XRPL Vanity 的通知已开启，且“勿扰”已关闭。用短词进行长时间搜索可能积攒数百条通知，Windows 会逐条显示。

一个单词的用时远超估算

估算是平均值，搜索可能远超这个时间。如果一个单词的首字母很少出现在 r 之后，它会比按长度推算的稀有约 23 倍，可以试试从第 2 或第 3 个字符开始选项。详见桌面应用指南。
