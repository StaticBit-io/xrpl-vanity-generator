把你的单词放进 XRP Ledger 地址

一款在处理器和显卡上离线运行的靓号地址生成器。

GitHub 上的源代码

一个读得出来的地址

靓号地址和其他 XRP Ledger 地址用法完全一样。你会同时拿到控制它的种子。

单词放在你想要的位置

可以严格区分大小写，也可以忽略。一次搜索可以包含多个单词。

方式找到的地址
开头为rDiAMond...
从第 2 或第 3 个字符开始r9DiAMond...
结尾为r...DiAMond
任意位置r...DiAMond...
开头和结尾为rDiA...Mond

每多一个字符，等待时间最多增加到 58 倍。桌面应用会在开始前显示预计用时。

种子只留在你的电脑上

谁拥有种子，谁就控制账户。

没有联网代码
没有账户、服务器、遥测，也不检查更新。
安全的随机数
密钥来自系统的加密随机数生成器。
桌面应用更安全
结果按你的 Windows 账户加密，种子默认隐藏。命令行会以明文输出种子。
用二维码代替文件
扫码将钱包导入 StaticBit 应用，也可以设置密码。
可阅读的源代码
在向生成的地址存入真实资金之前，请先自行编译程序。

桌面应用
