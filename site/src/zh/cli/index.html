xrpl-vanity 命令行

与桌面应用相同的靓号地址搜索，在 Windows 或 Linux 终端中运行。

编译

没有预编译的程序：请使用 .NET 10 SDK 从源代码运行。

$ git clone https://github.com/StaticBit-io/xrpl-vanity-generator.git
$ cd xrpl-vanity-generator
$ dotnet run --project src/XrplVanity.Cli -c Release -- --contains xrp --count 1

第一次运行会编译程序。在下面的示例中，xrpl-vanity 代表 dotnet run --project src/XrplVanity.Cli -c Release --。

单词放在哪里

不带选项的单词必须出现在地址开头，紧跟在开头的 r 之后。一次运行可以混用多种位置，只要任意一个模式匹配，地址就算匹配。

$ xrpl-vanity ripple hodl xrp
$ xrpl-vanity --ends xyz --contains dao
$ xrpl-vanity --starts-ends abc:xyz
$ xrpl-vanity --list words.txt 5

--starts-ends 要求两部分出现在同一个地址中，所以耗时相当于一个长度为两者之和的单词。最后一行从文件载入单词，只保留至少 5 个字符的。

选项

选项默认值作用
--starts P无在地址开头、r 之后匹配。可重复。不带选项的单词效果相同。
--near-start P无允许单词从第 2 或第 3 个字符开始。可重复。
--ends P无在地址结尾匹配。可重复。
--contains P无在任意位置匹配。可重复。
--starts-ends PREFIX:SUFFIX无要求同一地址同时有前缀和后缀。可重复。
--near-starts-ends PREFIX:SUFFIX无同上，但前缀可从第 2 或第 3 个字符开始。可重复。
--list FILE [minLen]minLen 4从文件载入用于地址开头的单词。
--case-sensitive关闭严格按输入匹配。默认情况下，12 个字符以内的单词任意大小写组合都算匹配。
--threads N全部核心处理器搜索使用的线程数。使用 --gpu 时忽略。
--out FILE无在输出的同时把匹配追加到文件中。
--count N无找到 N 个匹配后停止。否则一直搜索，直到你按下 Ctrl+C。
--gpu关闭在显卡上搜索：优先 CUDA，其次 OpenCL。
--backend NAME无强制使用 cuda 或 opencl。隐含 --gpu。
--device N无按编号选择设备。隐含 --gpu。
--list-devices无列出所有设备后退出。
--gpu-devices SPEC无同时使用多个设备：all、cuda、opencl 或逗号分隔的列表。隐含 --gpu。
--gpu-duty N100让显卡约 N% 的时间处于工作状态，范围 1 到 100。

哪些单词可用

地址由 58 种字符组成。0、O、I 和 l 不存在，所以你的单词会被调整：l 变为 L，0 和 O 变为 o，I 变为 i。调整后仍含有不可能字符的单词会被报告并跳过。

每多一个字符，等待时间都会成倍增加：使用 --case-sensitive 时最多 58 倍，不使用时增幅更小，因为更多写法都算作匹配。

r 之后的第一个字符通常是 pshnaf39wBUDNEGHJKLM4PQ 之一。以其他字符开头的单词，出现的概率只有按长度推算值的约 1/23。--near-start 允许它晚一个字符开始，这样找到它所需的时间约为原来的 1/24。

在显卡上搜索

$ xrpl-vanity --list-devices
$ xrpl-vanity --gpu --contains dao --count 1
$ xrpl-vanity --gpu-devices cuda --starts abc
$ xrpl-vanity --gpu --gpu-duty 80 --contains dao --count 1 --out dao.tsv

显卡找到的每个匹配都会在处理器上重新计算验证，只有两者一致时才会输出：出故障的设备只会拖慢速度，绝不会给你错误的密钥。没有可用设备时，--gpu 会以代码 2 退出，而不是退回处理器。

首次运行 OpenCL 时，驱动编译程序可能需要几十秒。之后的运行会很快。--gpu-duty 为其他应用留出余量，速度大致按比例下降。--gpu-devices all 会在每个后端各打开一次每张显卡，所以要让每张 NVIDIA 显卡只用一次，请使用 --gpu-devices cuda。

结果和退出代码

每个匹配在终端中显示为一行：

Address: r...	Seed: sEd...

--out FILE 会追加同样的一对值，用制表符分隔，不带标签。警告和最终速度输出到 stderr，所以重定向 stdout 时只会得到匹配。

谁拥有种子，谁就控制账户。匹配以明文出现在终端和该文件中，别处都没有。请妥善保密。

代码含义
0达到了 --count 的目标。
2用法错误、没有可匹配的模式、没有可用显卡，或搜索失败。
130在达到 --count 目标之前被 Ctrl+C 中止。
