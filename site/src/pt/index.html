Sua palavra em um endereço do XRP Ledger

Um gerador de endereços personalizados que funciona offline no processador e na placa de vídeo.

Código no GitHub

Um endereço que dá para ler

Um endereço personalizado funciona como qualquer outro endereço do XRP Ledger. Você o recebe junto com a seed que o controla.

A palavra onde você quiser

Diferenciando maiúsculas e minúsculas ou não. Uma busca pode ter várias palavras.

ModoEncontra

Cada caractere a mais multiplica a espera por até 58. O aplicativo mostra o tempo esperado antes de você começar.

Sua seed fica no seu computador

Quem tem a seed controla a conta.

Nenhum código de rede
Sem conta, servidor, telemetria ou verificação de atualizações.
Aleatoriedade segura
As chaves vêm do gerador criptográfico do sistema.
Mais seguro no aplicativo
Resultados criptografados para sua conta do Windows, seeds ocultas. A linha de comando mostra as seeds em texto puro.
QR em vez de arquivo
Importe uma carteira no aplicativo StaticBit escaneando um código QR, com senha se quiser.
Código que você pode ler
Compile você mesmo antes que uma chave guarde fundos de verdade.

Aplicativo para Windows

Windows 10 versão 1809 ou mais recente, x64, com o runtime do WebView2.

Linha de comando

Compilada a partir do código com o .NET 10 SDK. Verificada no Windows e no Linux.

Carga da GPU

Use vários dispositivos ao mesmo tempo, ou limite a carga e continue trabalhando.

Só chaves Ed25519. Endereços secp256k1 não são suportados.
