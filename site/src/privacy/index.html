Privacy policy

XRPL Vanity, the desktop application for Windows, published by StaticBit.

Last updated: 2026-11-04.

Summary

The application collects nothing, sends nothing, and has no account system. It has no network code at all: no telemetry, no analytics, no crash reporting, no update check, no licence check. Everything it produces stays on the computer that produced it, unless you move it yourself: by exporting a file, copying a seed or showing a QR code.

What the application stores

Both files live in the application's own local data folder. The Settings page prints the resolved path and opens the folder on request.

FileContentsProtection
settings.jsonInterface preferences: pattern and target drafts, thread count, GPU duty, match limit, window size, close behaviour, notification flag, clipboard and reveal timeouts, and the last measured search rate per device.Plain JSON. It holds no keys and no personal data.
results.datThe generated addresses and their seeds.Encrypted with the Windows Data Protection API (DPAPI) under CurrentUser scope, so only the Windows account that wrote the file can decrypt it.

A seed is the secret that controls an XRP Ledger account. results.dat is the only file the application writes that contains one. No seed is ever written to a log, shown in a notification, or placed in the tray menu.

If you export results to a TSV file, that file contains seeds in plain text. It is written where you ask for it, and it is not encrypted — protecting it is up to you.

Clipboard

Copying a seed places it on the Windows clipboard and clears it after a delay you configure, and only if the clipboard still holds that same seed. Copying anything else in the meantime leaves your newer content alone.

A copied seed stays out of Windows clipboard history and clipboard sync.

QR codes

A result can be shown as a QR code for the StaticBit mobile wallet. A password is optional and encrypts the code; without one the code on your screen is not encrypted, and anyone who can see or photograph it can read the seed. A code holding a bare seed is never encrypted. The code is never written to disk and hides itself after 60 seconds.

Network

The application makes no network connections. The only traffic it can cause is a link you click yourself in the About section or elsewhere in the interface, which opens in your default browser; from that point the destination site's own privacy policy applies. The address search itself never contacts the XRP Ledger or any server — it generates and tests candidates entirely offline.

This website

This site loads only its own files. It sets no cookies and runs no analytics.

Children

The application is not directed at children and collects no information from anyone.

Removing your data

Uninstalling removes the application and its data folder, including results.dat and every seed in it, and they cannot be recovered. Save the seeds you want to keep first. To delete the stored results without uninstalling, use Open folder on the Settings page and delete results.dat and settings.json.
