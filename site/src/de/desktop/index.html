Desktop-Anwendung

Suchen Sie eine Vanity-Adresse, bewahren Sie die Ergebnisse verschlüsselt auf und übertragen Sie eine Wallet auf Ihr Telefon.

Bezugsquelle

Die Anwendung kommt in den Microsoft Store. Bis dahin lässt sie sich aus dem Quellcode bauen.

  • Windows 10 Version 1809 (Build 17763) oder neuer, x64.
  • Die Microsoft-Edge-WebView2-Laufzeit. Windows 11 und aktuelle Windows-10-Updates bringen sie mit.
  • Für die Suche auf der Grafikkarte ein NVIDIA-Treiber (CUDA, Turing-Karten ab 2018) oder eine beliebige installierte OpenCL-Plattform. Ohne beides sucht die Anwendung auf dem Prozessor und sagt das auch.

Einführung

Beim ersten Öffnen bietet die Anwendung einen kurzen Rundgang durch eine echte Suche an, vom Hinzufügen eines Worts bis zum Ergebnis und seinem QR-Code. Der gefundene Treffer wird nicht gespeichert, und Ihre eigenen Wörter und Einstellungen sind danach wieder da. Das Angebot kommt einmal: Für eine Wiederholung drücken Sie Einführung starten auf der Seite „Einstellungen“.

Suche

Wörter hinzufügen

Geben Sie ein Wort ein, wählen Sie die Position und fügen Sie es als Regel hinzu: beginnt mit, endet mit, irgendwo oder beginnt und endet mit, wofür beide Hälften in derselben Adresse stehen müssen. Regeln ignorieren Groß- und Kleinschreibung, solange Sie das nicht abschalten, und eine Suche kann viele Regeln enthalten.

Die Zeichen 0, O, I und l gibt es in Adressen nicht. Sie werden durch o, i und L ersetzt, und die Regel zeigt das Ergebnis neben Ihrer Eingabe.

Das Zeichen direkt nach dem führenden r ist eingeschränkt, deshalb sind manche Wörter etwa 23-mal seltener, als ihre Länge vermuten lässt. Das Kästchen am 2. oder 3. Zeichen lässt das Wort ein Zeichen später beginnen. Findet die Suche es so mindestens doppelt so schnell, schlägt die Anwendung das an der Regel vor. Standardmäßig ist es aus, weil es das Schriftbild der Adresse ändert.

Liste speichern schreibt Ihre Regeln in eine Textdatei. Liste laden fügt die Regeln aus einer Datei zur Liste auf dem Bildschirm hinzu und überspringt Duplikate.

Wählen, wo gesucht wird

Wählen Sie den Prozessor mit der gewünschten Zahl an Threads und dazu die CUDA- und OpenCL-Geräte, die die Anwendung gefunden hat. Alle können gleichzeitig laufen.

Der Regler GPU-Auslastung legt fest, welchen Anteil der Zeit die Grafikkarte arbeitet, von 25 bis 100 %. Ein niedrigerer Wert hält die Karte für andere Programme frei, und Änderungen wirken auch während einer laufenden Suche sofort.

Schätzung prüfen

Vor dem Start zeigt die Seite, wie viele Adressen ein Treffer im Mittel braucht und wie lange das auf den gewählten Geräten dauert. Sie nutzt die zuletzt gemessene Geschwindigkeit jedes Geräts. Beim ersten Mal gibt es noch keine, drücken Sie also Geschwindigkeit messen oder suchen Sie einmal.

Suche starten

Die Seite zeigt die aktuelle Geschwindigkeit, die geprüften Adressen und die Treffer. Jeder Treffer landet mit Adresse, Regel, Gerät und Uhrzeit in der Ergebnisliste. Nach N Treffern stoppen in den Einstellungen beendet die Suche von selbst.

Eine lange Suche kann im Infobereich weiterlaufen. Dort lässt sich auch die GPU-Auslastung einstellen. Eine Benachrichtigung meldet jeden Treffer und das Ende einer Suche.

Ergebnisse und Verlauf

Der Verlauf enthält jedes Ergebnis, das die Anwendung gespeichert hat. Grenzen Sie ihn mit dem Textfeld ein, das Adressen und Muster durchsucht, und mit der Musterliste. Haken Sie Zeilen an oder nutzen Sie alle angezeigten wählen, um sie gemeinsam zu exportieren oder zu löschen.

Ein gelöschtes Ergebnis lässt sich nicht zurückholen: Der Seed ist weg und mit ihm das Konto, sofern Sie ihn nicht anderswo gesichert haben.

Ein TSV-Export enthält Seeds im Klartext. Er landet, wo Sie wollen, und ist nicht geschützt, behandeln Sie die Datei also als das Geheimnis, das sie ist.

Seeds

Ein Seed gibt Zugriff auf sein Konto. Er ist überall verdeckt, bis Sie ihn anzeigen, und verbirgt sich nach 15 Sekunden oder beim Verlassen der Seite wieder. Ein kopierter Seed wird nach 30 Sekunden aus der Zwischenablage gelöscht, sofern Sie bis dahin nichts anderes kopiert haben. Beide Zeiten lassen sich in den Einstellungen ändern.

Ein kopierter Seed landet weder im Windows-Zwischenablageverlauf noch in der Synchronisierung der Zwischenablage.

Ergebnisse liegen in einer Datei, results.dat, verschlüsselt mit der Windows Data Protection API (DPAPI). Nur das Windows-Konto, das die Datei geschrieben hat, kann sie lesen, die Ergebnisse wandern also nicht auf ein anderes Konto oder einen anderen Computer. Kein Seed erscheint in einem Protokoll, einer Benachrichtigung oder dem Menü im Infobereich.

Beim Deinstallieren wird results.dat gelöscht, mit jedem Seed darin. Sichern Sie vorher die Seeds, die Sie behalten wollen.

Wallet aufs Telefon übertragen

Die QR-Schaltfläche an einem Ergebnis zeigt diese Wallet, QR anzeigen zeigt alle gewählten Zeilen. Scannen Sie den Code mit der Mobil-Wallet StaticBit, die die Wallets aus dem Sicherungsformat im Code wiederherstellt. Ein Code fasst bis zu 22 Wallets, mit Passwort 21.

Setzen Sie ein Passwort, wenn jemand Ihren Bildschirm sehen könnte. Es ist optional und verschlüsselt den Code. Ohne Passwort ist der Code unverschlüsselt, und der Dialog sagt das. Der Code wird nie auf die Festplatte geschrieben und verbirgt sich nach 60 Sekunden.

Ein einzelner Seed lässt sich auch als Code für eine Wallet zeigen. Dieser Code ist immer unverschlüsselt: Ein Passwort lässt sich dafür nicht setzen, und der Dialog weist darauf hin. Die Wallet StaticBit kann ihn ebenfalls scannen.
