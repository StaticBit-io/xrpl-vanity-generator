Ihr Wort in einer XRP-Ledger-Adresse

Ein Generator für Vanity-Adressen, der offline auf Prozessor und Grafikkarte läuft.

Quellcode auf GitHub

Eine Adresse, die man lesen kann

Eine Vanity-Adresse funktioniert wie jede andere XRP-Ledger-Adresse. Sie erhalten sie zusammen mit dem Seed, der Zugriff auf sie gibt.

Das Wort steht, wo Sie es wollen

Mit exakter Groß- und Kleinschreibung oder ohne. Eine Suche kann mehrere Wörter enthalten.

ModusFindet
Beginnt mitrDiAMond...
Beginnt am 2. oder 3. Zeichenr9DiAMond...
Endet mitr...DiAMond
Irgendwor...DiAMond...
Beginnt und endet mitrDiA...Mond

Jedes weitere Zeichen erhöht die Wartezeit auf bis zu das 58-Fache. Die Anwendung zeigt die erwartete Zeit, bevor Sie starten.

Ihr Seed bleibt auf Ihrem Computer

Wer einen Seed besitzt, verfügt über das Konto.

Kein Netzwerkcode
Kein Konto, kein Server, keine Telemetrie, keine Updateprüfung.
Sicherer Zufall
Die Schlüssel stammen aus dem kryptografischen Zufallsgenerator des Systems.
Sicherer in der Anwendung
Ergebnisse sind für Ihr Windows-Konto verschlüsselt, Seeds verdeckt. Die Kommandozeile gibt Seeds im Klartext aus.
QR statt Datei
Übertragen Sie eine Wallet per Scan in die StaticBit-App, auf Wunsch mit Passwort.
Lesbarer Quellcode
Bauen Sie das Programm selbst, bevor Sie echtes Guthaben auf eine damit erzeugte Adresse schicken.
