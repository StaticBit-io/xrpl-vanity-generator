Desktop app

Search for a vanity address, keep the results encrypted, and move a wallet to your phone.

Get it

Download the ZIP from the latest release, unpack it into any folder and run XRPL Vanity.exe. Nothing gets installed. The release page lists the file's SHA-256, so you can check your copy before you run it. You can also build it from source.

The file is not signed yet, so Windows may stop the first start with Windows protected your PC. Click More info, then Run anyway. Each new version may ask once more.

The ZIP version does not update itself: a new version is a new ZIP on the releases page. The application is also on its way to the Microsoft Store.

Results and settings are kept outside the application folder, in %LOCALAPPDATA%\StaticBit\io.staticbit.vanity. To remove the application, delete both folders: with the application folder alone, your results and their seeds stay on the disk.

  • Windows 10 version 1809 (build 17763) or newer, x64.
  • The Microsoft Edge WebView2 runtime. Windows 11 and current Windows 10 updates include it.
  • For GPU search, an NVIDIA driver (CUDA, on Turing cards from 2018 or newer) or any installed OpenCL platform. Without either, the application searches on the CPU and says so.

Tutorial

The first time you open the application, it offers a short walk through one real search, from adding a word to seeing a result and its QR code. The match it finds is not saved, and your own words and settings are back when it ends. You are offered it once: to run it again, press Start tutorial on the Settings page.

Search

Add your words

Type a word, pick a position, and add it as a rule: starts with, ends with, contains, or starts and ends with, which asks for both halves on one address. Rules ignore case unless you turn that off, and one search can hold many rules.

The characters 0, O, I and l do not exist in an address. They are replaced by o, i and L, and the rule shows the result next to what you typed.

The character right after the leading r is limited, so some words are about 23 times rarer than their length suggests. The 2nd or 3rd char box lets the word begin one character later. When that would find it at least twice as fast, the application offers it on the rule. It stays off by default because it changes how the address reads.

Save list and Load list keep a set of rules in a text file. Loading adds to the rules on screen and skips duplicates.

Choose where to search

Tick the CPU, with a thread count, and any CUDA and OpenCL devices the application found. They can all run at once.

The GPU duty control sets the share of the time the GPU works, from 25–100 %. A lower value leaves the card free for other applications, and a change reaches a running search at once.

Check the estimate

Before you start, the page shows how many candidates a match should take and the expected time on the devices you ticked. It uses the speed last measured on each device. On a first run there is none yet, so press measure speed or run a search once.

Run it

The page shows the live speed, the candidates tried and the hits. Each hit lands in the results list with its address, rule, device and time. Stop after N matches in Settings ends the search by itself.

A long search can run from the tray, which also holds the duty control. A notification tells you when a match arrives or a search finishes.

Results and history

History holds every result the application has stored. Narrow it with the text box, which searches addresses and patterns, and with the pattern list. Tick rows, or select all shown, to export or delete them together.

Deleting a result cannot be undone: the seed is gone, and with it the account unless you saved it elsewhere.

A TSV export holds seeds in plain text. It goes where you choose and is not protected, so treat that file as the secret it is.

Seeds

A seed controls its account. It is masked everywhere until you reveal it, and it hides again after 15 seconds or when you leave the page. A copied seed is cleared from the clipboard after 30 seconds, unless you have copied something else by then. Both delays are yours to change in Settings.

A copied seed stays out of Windows clipboard history and clipboard sync.

Results are stored in one file, results.dat, encrypted with the Windows Data Protection API (DPAPI). Only the Windows account that wrote the file can read it, so results do not move to another account or computer. No seed appears in a log, a notification or the tray menu.

Deleting the application's data deletes results.dat, and every seed in it. Save the seeds you want to keep first.

Move a wallet to your phone

The QR button on a result shows that wallet, and Show QR shows every selected row. Scan the code with the StaticBit mobile wallet, which restores it from the backup format the code carries. One code holds up to 22 wallets, or 21 with a password.

Set a password if anyone could see your screen. It is optional and encrypts the code. Without it the code is not encrypted, and the dialog says so. The code is never written to disk and hides itself after 60 seconds.

A bare seed can also be shown as a code for a single wallet. That code is never encrypted: it takes no password, and the dialog says so. The StaticBit wallet can scan it too.
