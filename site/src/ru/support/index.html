Частые проблемы

Окно открывается пустым или пишет, что страница недоступна

Не установлена среда выполнения WebView2. Установите Evergreen WebView2 runtime и снова откройте приложение.

Кроме процессора, устройств в списке нет

Приложение находит CUDA через драйвер NVIDIA, а OpenCL через установленные драйверы. Установите или обновите драйвер видеокарты и нажмите «Обновить список устройств» в карточке «Устройства». Перезапускать приложение не нужно.

Строка устройства краснеет во время поиска

Это устройство дало сбой, например после сброса драйвера, и сообщение об этом есть в строке. Остальные устройства продолжают работать. Поиск завершится, только если откажут все.

История доступна только для чтения

Приложение не смогло прочитать или записать файл с результатами, причина написана в плашке на странице «История». Обычно файл записан другой учётной записью Windows или скопирован с другого компьютера: результаты открываются только той учётной записью, которая их записала. Переместите файл в другое место, чтобы начать историю заново.

Уведомления не появляются

На странице настроек видно, приняла ли их Windows. Если приняла, проверьте в параметрах Windows, в разделе «Система» и «Уведомления», что уведомления для XRPL Vanity включены, а режим «Не беспокоить» выключен. Долгий поиск с коротким словом может поставить в очередь сотни уведомлений, и Windows показывает их по одному.

Слово ищется намного дольше оценки

Оценка показывает среднее, и поиск может идти заметно дольше. Слово, первая буква которого редко стоит после r, встречается примерно в 23 раза реже, чем можно ждать по его длине, поэтому попробуйте флажок со 2-го или 3-го символа. Подробнее в руководстве по приложению.
