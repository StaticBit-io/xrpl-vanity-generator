Ваше слово в адресе XRP Ledger

Генератор красивых адресов, который работает офлайн на процессоре и видеокарте.

Исходники на GitHub

Адрес, который можно прочитать

Красивый адрес работает как любой другой адрес XRP Ledger. Вы получаете его вместе с seed, который им управляет.

Слово там, где вы хотите

С учётом регистра или без него. В одном поиске может быть несколько слов.

ВариантЧто найдёт
Начинается сrDiAMond...
Начинается со 2-го или 3-го символаr9DiAMond...
Заканчивается наr...DiAMond
Где угодноr...DiAMond...
Начинается и заканчиваетсяrDiA...Mond

Каждый лишний символ увеличивает ожидание до 58 раз. Приложение показывает ожидаемое время ещё до запуска.

Seed остаётся на вашем компьютере

У кого seed, тот и распоряжается счётом.

Никакой работы с сетью
Ни учётной записи, ни сервера, ни телеметрии, ни проверки обновлений.
Надёжная случайность
Ключи берутся из криптографического генератора системы.
В приложении надёжнее
Результаты зашифрованы для вашей учётной записи Windows, seed скрыты. Командная строка выводит seed открытым текстом.
QR-код вместо файла
Перенесите кошелёк в приложение StaticBit сканированием, при желании с паролем.
Открытый исходный код
Соберите программу сами, прежде чем держать на ключе настоящие средства.

Приложение для Windows

Windows 10 версии 1809 или новее, x64, со средой выполнения WebView2.

Командная строка

Собирается из исходников с .NET 10 SDK. Проверена на Windows и Linux.

Нагрузка на видеокарту

Ищите на нескольких устройствах сразу или ограничьте нагрузку и продолжайте работать.

Только ключи Ed25519. Адреса secp256k1 не поддерживаются.
