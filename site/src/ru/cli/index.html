Командная строка xrpl-vanity

Тот же поиск красивых адресов, что и в приложении, но из терминала Windows или Linux.

Сборка

Готовых сборок нет: запускайте из исходников с .NET 10 SDK.

$ git clone https://github.com/StaticBit-io/xrpl-vanity-generator.git
$ cd xrpl-vanity-generator
$ dotnet run --project src/XrplVanity.Cli -c Release -- --contains xrp --count 1

Первый запуск собирает программу. В примерах ниже xrpl-vanity означает dotnet run --project src/XrplVanity.Cli -c Release --.

Где должно стоять слово

Слово без флага должно стоять в начале адреса, сразу после начальной r. В одном запуске можно смешивать позиции: адрес подходит, если совпал хотя бы один шаблон.

$ xrpl-vanity ripple hodl xrp
$ xrpl-vanity --ends xyz --contains dao
$ xrpl-vanity --starts-ends abc:xyz
$ xrpl-vanity --list words.txt 5

--starts-ends требует обе половины в одном адресе, поэтому ищется так же долго, как одно слово их общей длины. Последняя строка берёт слова из файла и оставляет те, в которых не меньше 5 символов.

Параметры

Какие слова подходят

В адресах 58 символов. 0, O, I и l в них нет, поэтому слово подправляется: l становится L, 0 и O становятся o, а I становится i. Если в слове всё равно остался невозможный символ, программа сообщает об этом и пропускает его.

Каждый лишний символ увеличивает ожидание: до 58 раз с --case-sensitive и меньше без него, потому что совпадением считается больше написаний.

Первый символ после r обычно один из pshnaf39wBUDNEGHJKLM4PQ. Слово, которое начинается с другого символа, встречается примерно в 23 раза реже, чем можно ждать по его длине. --near-start разрешает ему начаться на символ позже, и тогда оно находится примерно в 24 раза быстрее.

Поиск на видеокарте

$ xrpl-vanity --list-devices
$ xrpl-vanity --gpu --contains dao --count 1
$ xrpl-vanity --gpu-devices cuda --starts abc
$ xrpl-vanity --gpu --gpu-duty 80 --contains dao --count 1 --out dao.tsv

Каждое совпадение с видеокарты заново выводится на процессоре и печатается, только если результаты сошлись: сбойное устройство отнимает скорость, но никогда не выдаст неверный ключ. Если подходящего устройства нет, --gpu завершается с кодом 2 и не переходит на процессор.

Первый запуск OpenCL может занять десятки секунд, пока драйвер компилирует программу. Следующие запуски быстрые. --gpu-duty оставляет место другим программам, и скорость падает примерно пропорционально. --gpu-devices all открывает каждую карту по разу на каждый бэкенд, поэтому, чтобы задействовать каждую карту NVIDIA ровно один раз, используйте --gpu-devices cuda.

Результаты и коды выхода

Каждое совпадение выводится в терминал одной строкой:

Address: r...	Seed: sEd...

--out FILE дописывает ту же пару через табуляцию, без подписей. Предупреждения и итоговая скорость идут в stderr, поэтому в stdout остаются только совпадения.

У кого seed, тот и распоряжается счётом. Совпадения хранятся открытым текстом, в терминале и в этом файле, и больше нигде. Не показывайте их никому.

КодЗначение
0Набрано нужное число совпадений из --count.
2Неверные параметры, ни одного достижимого шаблона, нет подходящей видеокарты или поиск прервался с ошибкой.
130Прервано через Ctrl+C до того, как набралось число из --count.
