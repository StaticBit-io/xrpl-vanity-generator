Common problems

The window opens blank or shows "can't reach this page"

The WebView2 runtime is missing. Install the Evergreen WebView2 runtime and open the application again.

No devices are listed beyond the CPU

The application finds CUDA through the NVIDIA driver and OpenCL through the installed drivers. Install or update your GPU driver, then press the refresh button on the Devices card. You do not need to restart.

A device row turns red during a search

That device failed, for example after a driver reset, and the message is on the row. The other devices keep running. The search only ends if all of them fail.

History is read-only

The application could not read or write its results file, and the banner on the History page gives the reason. Usually the file was written by another Windows account or copied from another computer: results can only be opened by the account that wrote them. Move the file aside to start a fresh history.

Notifications never appear

The Settings page says whether Windows accepted them. If it did, check that notifications are on for XRPL Vanity in Windows Settings, under System and Notifications, and that do not disturb is off. A long run with a short word can queue hundreds of notifications, and Windows shows them one at a time.

A word is taking far longer than the estimate

The estimate is an average, and a search can run well past it. A word whose first letter rarely follows the r is about 23 times rarer than its length suggests, so try the 2nd or 3rd char option. See the desktop guide.
